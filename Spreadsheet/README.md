# Spreadsheet

Workspace for DevForge spreadsheet-related files and project data.

Open a `.Prime` file in VS Code to edit it in the Prime Spreadsheet grid. Use
**Open text** in the grid to inspect or edit the original format. The No Man's
Sky file on this review branch contains the confirmed rows from `origin/dev`.
The older unsaved local version and empty `sub2.Prime` placeholder are preserved
byte for byte in `Drafts/` until their intended data is confirmed.
