# DevForge Codex Handoff Area

The `.CODEX/` directory is the shared checkpoint and communication area for
approved Codex sessions working on DevForge from different devices.

## Rules

- Read the newest handoff before starting related work.
- Preserve earlier handoff history.
- Update the matching handoff's response section with results and remaining blockers.
- Never place passwords, access tokens, private keys, or other credentials here.
- Do not delete or overwrite project files unless Jacob explicitly approves it.
- Keep device-specific fixes safe and avoid replacing unrelated system packages.
- Use a review branch and pull request for repository changes unless Jacob directs otherwise.
